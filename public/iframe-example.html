Sitio Web Principal

Este es un ejemplo de cómo integrar nuestro chat como un widget flotante utilizando un iframe.

El chat se ubica en la esquina inferior derecha de la página y puede minimizarse/maximizarse.

Características del Widget

  • Integración sencilla mediante iframe
  • Posicionamiento flotante en la esquina inferior derecha
  • Posibilidad de minimizar/maximizar
  • Comunicación bidireccional entre la página principal y el iframe
  • Adaptable a diferentes tamaños de pantalla

Instrucciones de Implementación

Para implementar este widget en tu sitio web, simplemente añade el siguiente código HTML: 


<div id="chat-container" class="chat-iframe-container">
    <iframe src="https://tu-dominio.com/widget" class="chat-iframe" id="chat-iframe"></iframe>
</div>
