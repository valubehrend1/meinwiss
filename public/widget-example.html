Página de ejemplo con Chat Widget

Contenido principal

Este es un ejemplo de cómo integrar el widget de chat en cualquier página web. El widget aparece en la esquina inferior derecha y se puede minimizar/maximizar.

El chat se carga en un iframe que apunta a la ruta '/widget' de tu aplicación React.

Cómo funciona

El chat se comunica con la página principal a través de mensajes postMessage, lo que permite controlar su estado desde la página donde está embebido.

Características

  • Diseño responsivo que se adapta a diferentes tamaños de pantalla
  • Funcionalidad de minimizar/maximizar
  • Comunicación bidireccional entre el iframe y la página principal
  • Estilos personalizables

Información

Puedes controlar el chat mediante JavaScript:

// Minimizar el chat
document.getElementById('minimizeChat').addEventListener('click', function() {
    const chatFrame = document.getElementById('chatWidget');
    chatFrame.contentWindow.postMessage({
        type: 'PARENT_COMMAND',
        command: 'minimize'
    }, '*');
    chatFrame.classList.add('chat-widget-minimized');
});

// Maximizar el chat
document.getElementById('maximizeChat').addEventListener('click', function() {
    const chatFrame = document.getElementById('chatWidget');
    chatFrame.contentWindow.postMessage({
        type: 'PARENT_COMMAND',
        command: 'maximize'
    }, '*');
    chatFrame.classList.remove('chat-widget-minimized');
});
